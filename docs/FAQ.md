# FAQ

## What is this repository for?

This repo is a practical collection of GenAI and LangChain examples designed for learning and experimentation.

## Do I need to know Python first?

Basic Python knowledge helps, but many examples are beginner-friendly and can be studied step by step.

## Do I need API keys?

Some examples use OpenAI or other model providers. If an example depends on an API, you will need the relevant key configured in your environment.

## Can I use this repo for my own project?

Yes. This repository is meant for experimentation, adaptation, and custom project building.

## What should I learn first?

Start with prompt basics, then move to model usage, chaining, and retrieval. RAG is a very useful next step.

## Why are the modules numbered?

The folder names were cleaned up for readability, but the original material still follows a learning progression.

## Is this a full production framework?

No — this is a learning repo and prototype playground, not a production-ready product template.

## Where should I begin?

Start with `01_foundations/`, then follow the learning path in `docs/Learning_Path.md`.
